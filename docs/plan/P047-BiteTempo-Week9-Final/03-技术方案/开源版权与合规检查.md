## 2. 开源规则简化版

- MIT：可商用、修改、闭源；保留版权及许可证文本。
- Apache 2.0：类似，但有 NOTICE（若存在）与变更记录等要求，兼有专利许可条款。
- GPL-3.0：一般不能把 GPL 代码直接合入然后向别人分发闭源的整体派生 APP；个人内部修改使用与分发不同。
- 无 LICENSE、来源不明、疑似复制内容：一律不作为可复用代码。
- 第三方截图、插画、音频要单独审查版权，不能因为代码仓库 MIT 就默认素材也 MIT。

## 3. 本包品牌 SVG

`prototype/assets/app-icon.svg` 与 `prototype/assets/splash.svg` 是本包代码绘制的原创临时方向 A 候选，供设计沟通与开发转换使用；需要根据最终确认方向调整成适配 Android Adaptive Icon 与 Splash 的实际资源。未经过用户品牌签收，**不自动当正式最终资产**。

## 4. 开发必须生成的实际清单

- `THIRD_PARTY_NOTICES.md`：每个实际进入 APK 的依赖、源项目、版本/commit、许可证、版权原文、NOTICE（如适用）、素材出处。
- `LICENSE-AUDIT.md`：说明候选是否被真正使用、未使用原因、最终授权风险。
- `SECURITY-REVIEW.md`：密钥、权限、网络发送文案及公开发布迁移要求。
