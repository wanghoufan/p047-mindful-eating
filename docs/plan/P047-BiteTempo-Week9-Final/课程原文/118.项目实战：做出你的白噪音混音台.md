# 118.项目实战：做出你的白噪音混音台


## 本课总结

1. Phase 3 的目标是白噪音混音台：6 条环境音、界面混音、音量调节、四档专注时长，以及组合的保存和恢复。
2. Claude Code 完成开发后留了三个问题：音频只是占位素材、混音台还没有页面入口、功能还没在真机上完整验证。
3. 为了测试把 Phase 4 的入口任务 T027、T028 提前做完，打通主页到专注计时页的完整链路。
4. 真实素材优先选带 CC0 声明的，比如 Wikimedia Commons，下载前要查看详情里的授权协议。
5. 用 ffmpeg 把来源各异的音频统一格式、处理循环和响度，需要署名的记进 license.md 方便版权合规。
6. 真机试音发现点 Begin Focus 没反应，让 Claude Code 定位，原来是按下回调里只有一行注释没写跳转。
7. 修好后多音轨同播、音量调节、倒计时都正常，最后把代码推送到 GitHub 完成本阶段备份。

---

这一节我们继续推进项目的第三阶段。开始之前，可以先打开我们的任务文档 tasks.md，看看具体要完成什么。第三阶段主要实现的是白噪音混音台：我们需要准备 6 条雨声、风声、海浪声之类的环境音，然后完成界面混音功能、音量调节、10、25、45、60 分钟的专注时长，以及混音组合的保存和恢复。这阶段验收目标也很明确：我们的混音台需要能播放多种声音，以及能够离线使用。

### 开始 Phase 3

首先我们新建一个 Claude Code 会话，然后使用 /speckit.implement 开始实现第三阶段。发送以后，Claude Code 会根据任务文档 tasks.md 逐项实现白噪音混音台，我们等待它完成开发和检查。这阶段的进度还是比较顺利的：从音频文件、音源加载器、混音组件、专注设置音量，以及最后的组合保存和恢复，任务都已经完成。Claude Code 也做了基础验证，依赖检查通过，项目可以正常打包，6 段音频也都成功包含在安装包里。

不过这也还不能说 Phase 3 完全验收通过，因为 Claude Code 提醒我们还有三个问题要处理。第一个也是最重要的：现在使用的 6 段音频还只是占位素材。Claude Code 为了先把功能跑通，生成了临时音频，并不是真实的雨声、海浪声这些环境录音，实际的听感和循环效果都还需要优化。后面我们需要找到授权明确、允许在产品中使用的真实音频素材进行替换，并且保存好对应的授权信息。第二个问题是，混音台虽然已经开发好了，但现在还没有入口可以进入：我们的首页有 Breath 和 Focus 两个入口，白噪音混音台属于 Focus 功能，但这部分页面搭建要到后面的阶段才会实现。所以目前混音功能代码已经写好了，但我们还没办法从 App 里正常打开它。第三个问题是，Claude Code 目前主要完成了代码检查和打包验证，代码在真机上完整测试混音功能——多个音频同时播放、实时调节音量、保存组合，以及重新打开后的恢复效果——都还要在真实设备上确认。

所以接下来要做的事情就很清楚了：先把 Focus 的入口接通，让我们能打开混音台；再替换成真实、版权明确的环境音；最后在真机上完整跑一遍测试，播放、混音、音量调节、保存和恢复。

### 把页面入口提前

为了测试 Phase 3 的混音台，我们可以先把后面和页面入口相关的任务提前到这阶段来做。不然功能虽然已经做完，但还没有入口能打开。那这里直接把需求告诉 Claude Code，发送以后，Claude Code 会自己去 tasks.md 里找对应任务，不需要我们手动指定。它识别到需要提前的是 Phase 4 里的 T027 和 T028，然后把这两个任务提前到当前阶段实现，把页面入口先接起来。修改完成以后，Claude Code 告诉我们，现在已经打通了从主页到专注页面、再到专注计时的完整链路，白噪音混音台也已经接进来了。

### 找真实的环境音素材

页面入口接通以后，我们还需要把前面的占位音频替换成真实的环境音。这里可以先让 Claude Code 推荐一些找白噪音素材的网站。发送以后，Claude Code 会给我们推荐一些音频素材平台。这里我们以先找带有 CC0 声明的为主。CC0 是 Creative Commons 提供的一种公共领域贡献工具，简单理解就是创作者会在法律允许的范围内尽可能放弃版权及相关权利，所以这些素材通常可以自由使用、修改和用于商业项目，也一般不要求署名。

那这次我们可以先看 commons.wikimedia.org，也就是 Wikimedia Commons 维基共享资源。它和维基百科属于同一个体系，里面可以搜索音频、图片、视频的大量共享素材。需要注意的是，Wikimedia Commons 里的素材版权不完全一样，有些是 CC0，有些需要署名，所以下载之前要查看详情里的授权协议。接下来就可以通过搜索来寻找我们需要的声音，比如雨声可以直接搜索 rain，再切换到 audio 分类。搜索结果出来以后可以多试听几个，找到合适的音源后进入详情页，把这个音频的下载链接先保存下来，后面我们会把这些链接一起交给 Claude Code，让它帮我们下载、整理并替换进项目。这里还有一个搜索小技巧：不要只搜声音的中文名，可以多用英文关键词，这样通常能够找到适合做白噪音的素材。

### ffmpeg 统一处理音频

6 个音源都齐了以后，我们就可以把链接一次性交给 Claude Code，让它帮我们下载、处理，替换掉前面的占位音频。发送以后，Claude Code 就会开始下载和处理这些音频，这个过程还会花一些时间，我们顺便了解一下它处理中用到的工具。ffmpeg 是一个很常用的音视频处理工具，可以做格式转换、剪辑、压缩、音频提取等等操作，这里 Claude Code 主要是用它把不同来源的音频统一处理成适合 App 使用的格式。具体来说，Claude Code 会先下载这 6 个音频，并且逐个核对授权信息，因为 Wikimedia Commons 上不同素材的 License 可能不一样，所以每个文件要单独确认。接着它会用 ffmpeg 统一音频格式、处理循环效果和统一响度，再替换掉项目里原来的占位音频。如果素材需要署名，Claude Code 还会把作者、来源链接按格式填写记录到 license.md，方便后续做版权合规。所以这一步它做了三件事：核对授权、处理音频、替换文件。如果想节省 Token，也可以自己先把音频下载到电脑，再让 Claude Code 直接处理本地文件。

### 打包到安卓真机测试

接下来我们让 Claude Code 帮我们打包，并且直接在安卓真机上测试。这里我们告诉 Claude Code：构建安卓版本，然后安装到连接的真机上。这一步需要先用 USB 数据线把安卓手机连接到电脑，并且开启开发者模式和 USB 调试。连接上手机以后，手机可能会弹出 USB 调试、数据传输或安装确认窗口，我们按提示允许就可以。Claude Code 会先检查我们的安卓开发环境，检测到手机后就会开始构建 App，并且把构建好的版本安装到手机上。

安装完成以后，我们打开 App，进入 Focus 专注功能。这里我们先分别试听一下，包括下雨、风声、海浪、白噪音、雨林和篝火，整体效果都比较符合预期。接下来测试混音功能：我们可以同时打开多个音轨，比如风声、海浪声、白噪音和雨声，再分别调整每个音轨的音量。不同音轨能够同时播放，单独调节音量也没问题，说明混音台功能基本正常。

### 修一个没有跳转的 Bug

不过继续测试时我们发现一个问题：点击 Begin Focus 开始专注以后没有反应，正常情况下这里应该进入专注计时页面，说明这个功能目前还有 Bug。那接下来就让 Claude Code 帮我们定位和解决这个问题，这里直接告诉 Claude Code 刚才测试时发现的问题。Claude Code 查了一遍代码以后发现，Begin Focus 按钮的 onPress 里面只有一行注释，没有真正写跳转到下一页的逻辑，所以我们刚才点击按钮时才没有任何反应。

现在 Claude Code 已经把这个问题修好了，我们再测试一次。回到 App，进入 Focus 功能，先选择 25 分钟，再打开混音台调整声音，然后点击 Begin Focus。可以看到这次我们成功进入了专注计时页面，倒计时也运行正常。而且在计时过程中，混音台也可以继续用，我们可以同时打开多个音轨，或者随时调整每个音轨的音量。这样白噪音混音台和专注计时这两个功能就都跑通了。

### 提交备份

接下来这一节的最后一个环节，我们还是把项目代码提交到 GitHub 上做一个备份。这里直接告诉 Claude Code，让它帮我们把代码推送到 GitHub。发送以后，Claude Code 就会帮我们检查这次的代码改动，然后完成提交和推送。等它提示操作完成，这次的代码备份就搞定了。我们下期见。
