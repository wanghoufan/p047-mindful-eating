### 第9周作业：结合 Spec Kit 开发一个 App

进行中

![](https://commonresource-1252524126.cdn.xiaoeknow.com/image/l75lkceh03u9.png)11人参与

本周作业的目标，是使用 Spec Kit 完整推进一次 App 开发，并且把项目真正运行到手机或模拟器上。

你可以继续完善前几周做过的 App，也可以重新做一个新的 App。主题不限，功能不用很多，重点是体验一次更规范的 SDD 开发流程。

## 作业任务

请使用 Spec Kit 完成一个 App 项目，并至少完成以下内容：

- 使用 `/speckit.constitution` 创建项目宪法；

- 使用 `/speckit.specify` 创建需求规格；

- 使用 `/speckit.plan` 制定技术计划；

- 使用 `/speckit.tasks` 拆解开发任务；

- 使用 `/speckit.implement` 按任务推进开发；

- App 至少完成一个可以真正使用的核心功能；

- 将 App 安装到真机或模拟器中进行测试。

核心功能可以根据自己的项目自由选择，例如：

- 喝水提醒 App：设置目标 + 记录喝水次数；

- 菜谱助手 App：输入现有食材 + 推荐菜谱；

- 阅读记录 App：记录正在读的书 + 保存阅读进度；

- 旅行打卡 App：记录去过的地点 + 添加照片和备注；

- 冰箱管理 App：记录现有食材 + 提醒快过期食品；

- 心愿清单 App：添加想完成的事情 + 标记完成。

## 进阶要求

在下面几个方向中，至少选择 2 项完成：

- 支持深色 / 浅色模式；

- 加入动画效果；

- 加入音频播放；

- 接入 AI 大模型；

- 支持中文 / 英文等多语言切换；

- 根据原型图优化 UI；

- 使用 Development Build 安装到真机。

## 提交内容

请提交：

1. 一句话介绍你的 App 是做什么的；

2. App 运行截图，至少 3 张；

3. 你完成的核心功能；

4. 你选择完成的进阶功能。

## 作业要求

- 必须使用 Spec Kit 完成 SDD 流程；

- 必须是 App 项目；

- 必须至少完成一个可用的核心功能；

- App 需要能在真机或模拟器中运行。
