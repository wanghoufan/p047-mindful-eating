# 113.怎么做安卓真机实测？


## 本课总结

1. 项目越来越完整后，有些功能已经不能只靠 ExpoGo 测试，涉及手机原生能力时需要 Development Build。
2. Development Build 是给当前项目生成的测试版 App，把需要的原生能力一起打包，效果更接近真正上线的版本。
3. 要装到安卓真机，先开启隐藏的开发者选项：连续点击版本号进入，再打开 USB 调试并允许授权。
4. 用 npx expo run:android 命令让 Claude Code 构建安卓版本，它会检查环境、构建再安装到连接的手机。
5. 这种开发测试版运行时通常还要连电脑上的开发服务，不是可以直接发给别人的版本，上架另有一课。
6. 真机测试更接近用户实际体验，通知、权限、拍照、蓝牙、陀螺仪、手势这些最好在真机上完整确认。

---

到目前为止我们更多还是用 ExpoGo 来快速验证，但随着项目越来越完整，有些功能已经不能只靠 ExpoGo 来测试了，特别是涉及手机原生能力的时候，就需要用到 Development Build。简单来说，Development Build 就是给当前项目重新生成一个测试版 App，把需要的原生能力一起打包进去，测试效果也会更接近真正上线的版本。那这一节我们再来了解怎么把 Expo 项目打包成安卓 APK，安装到自己手机上进行真机测试。

### 开启开发者选项和 USB 调试

要把 App 直接安装到安卓真机上测试，第一步就是打开手机里的开发者模式。安卓手机里有一个平时默认隐藏的开发者选项，里面放了很多开发场景的设置。对我们来说最重要的是 USB 调试，打开以后电脑才能通过数据线和手机建立调试连接，并且能把 App 安装到手机上。

大部分安卓手机的开启方法都差不多，这里以 vivo 举例。打开手机设置，进入关于手机，再找到版本信息，里面会有一项软件的版本号，英文系统里一般叫 Build Number。连续点击这一项几次，系统就会提示已经进入开发者模式。接下来返回设置，进入系统管理与升级，滑到下面就能看到开发者选项，点进去以后先打开开发者选项，再找到 USB 调试，开启它并且允许调试。

然后我们用数据线把手机连接到电脑。第一次连接上，手机一般会弹出相关授权提示，我们按提示允许文件访问，并且确认 USB 调试授权。完成这些设置以后，手机就准备好了，接下来我们就可以把测试版 App 安装到真机上。

### 让 Claude Code 构建并安装

这里以前面的项目为例子，新建一个 Claude Code 会话，让它帮我们完成安卓版本的构建和安装。其中 npx 的作用是直接调用这个项目里已经安装好的命令工具来执行任务；Expo 就是我们现在使用的 Expo 开发框架；run:android 表示把项目按安卓版本来构建，并且运行到连接的安卓设备上。所以整条命令的意思，就是用当前项目里的 Expo 工具把 App 编译成安卓版本，然后装到手机上运行。

发送以后，Claude Code 会先检查项目和电脑上的 Android 开发环境，确认没有问题之后就开始构建 App。第一次构建通常会花一点时间，Claude Code 会持续查看构建进度，等构建完成以后，再把生成的测试版 App 安装到已经连接的手机上。最后它又会告诉我们构建是否成功，以及安装包生成在电脑的哪个位置。

只要注意，我们现在构建的是开发测试版，这种版本主要适用于开发阶段，运行时通常还要连接电脑上的开发服务，所以它不是一个可以直接发给别人的版本。后面讲 App 打包和上架的时候，我们再学习怎么生成可以独立运行的版本。

### 在手机上完成安装

回到手机，可以看到 App 已经安装上了。因为这是没有经过应用商店发布的 APK，部分手机安装时会弹出安全提醒，确认这个安装包是我们自己构建的版本以后，按照系统提示继续安装就可以了。安装完成以后能够正常打开 App，就说明这次 Android 真机构建和安装成功了。

### 真机测试为什么不能省

相比模拟器，真机测试会更接近用户实际使用 App 的体验。比如通知能不能正常弹出、权限请求是不是正常、页面在真实屏幕上的表现，这些都最好在手机上确认。还有些功能必须放在真机上才能完整测试，比如拍照、蓝牙、陀螺仪、系统通知以及各种手势操作。所以模拟器更适合快速改页面、检查基础功能，但到了项目后期，真机测试一定不能少。我们下期见。
