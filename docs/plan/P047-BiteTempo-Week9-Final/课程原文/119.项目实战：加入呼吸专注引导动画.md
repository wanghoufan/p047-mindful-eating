# 119.项目实战：加入呼吸专注引导动画

## 本课总结

1. 第四阶段要做呼吸模式，首页已有专注和呼吸两个功能，本阶段核心目标是让呼吸光球动起来，把呼吸节奏提示和动效做好，对应任务T022到T029。
2. 用Spec Kit实现完打包到真机后，点击Breathe就报Unmatched Route，原因是用户输入页还没实现，Claude Code先做了临时跳转处理让我们继续测试。
3. 呼吸页面按节奏依次提示吸气、屏住、呼气，圆圈吸气放大、屏住不动、呼气缩小，整个过程轻柔，大约持续二十三分钟，呼吸模式核心动作跑通。
4. 让Claude Code配一套呼吸球专属音效，选中的呼吸声方向实际难听接近噪音，于是改让MiniMax重新生成适合呼吸模式的背景音乐。
5. 在MiniMax网站创建纯音乐，挑中一首平静轻柔的曲目下载无损音频，拖进项目文件夹后用Add引用，让Claude Code设置成Breathe模式的背景音乐。
6. 真机验证一进呼吸页面背景音乐自动播放，跟着画面提示呼吸搭配新BGM，整个呼吸过程的氛围舒服多了，呼吸引导动画和背景音乐完成。
7. 最后把项目当前代码提交推送到GitHub备份，这一阶段的开发告一段落，我们下期见。

---

### 第四阶段目标

我们第四阶段，首页现在有两个功能：一个是专注模式，通过白噪音混音台帮助用户专注；另一个是呼吸模式，让用户在焦虑或者想放松的时候，可以跟着 App 的动画节奏呼吸。第四阶段我们就把呼吸引导功能做出来。这个阶段核心的目标是让呼吸光球动起来，同时把呼吸节奏提示和动效做好，对应任务 T022 到 T029。接下来新开一个会话，模型可以按照自己的偏好选择，推荐用 Auto，然后让 Claude Code 执行 /speckit.implement。发送以后，Claude Code 就会按照这些文件开始实现这个阶段的内容。

### 真机测试遇到路由报错

开发之后我们还是用真机测试一下成果，直接让 Claude Code 帮我们重新打包并且安装到真机上。发送以后，Claude Code 会重新构建再安装到我们连接的手机上。安装完成以后我们打开 App 看一下，在首页点击第一个功能 Breathe 进入呼吸模式，结果刚点击就报错了，页面显示 Unmatched Route，下面还有一句 page not found，这就像我们会在网站里看到的 404 错误，说明 App 找不到我们要进入的这个页面，应该是路由出了问题。我们把遇到的问题直接告诉 Claude Code。

### 临时处理与快速刷新

发送以后，Claude Code 很快找到了原因：从首页到呼吸页面之间还有一个用户输入页，但这个页面属于后续阶段，现在还没有实现，所以点击 Breathe 以后就找不到对应的页面。为了让我们现在就能测试呼吸功能，Claude Code 先帮我们做了一个临时处理，让首页直接跳到呼吸页面。代码改完以后，App 里的页面也马上更新了，这是 React Native 开发时的 Fast Refresh，也就是快速刷新，只要 App 还连接着开发服务，大部分代码修改保存以后都可以马上看到效果。我们来到首页再点击 Breathe，这次就能正常进入呼吸页面了。页面会按照节奏依次提示我们吸气、屏住和呼气：吸气的时候中间的圆圈慢慢放大，屏住的时候保持不动，呼气的时候再慢慢缩小，整个过程会比较轻柔，大约持续二十三分钟。那这里呼吸模式的核心动作就跑通了，但现在只有很轻的配乐，和呼吸动画的配合还不够明显。

### 给呼吸球配专属音效

接下来我们给呼吸球单独加一套专属音效。新开一个会话，让 Claude Code 帮我们找一套适合呼吸球运动的音频，并且不要直接用 Focus 专注模式里已有的音频。发送以后，Claude Code 会先问我们希望音效是什么感觉，这里一共给了四个方向：第一个是跟着呼吸节奏变化的呼吸声，第二个是颂钵低鸣，第三个是在呼吸切换时播放提示音，第四个是自然声、有环绕感。感觉第一个和我们的呼吸动画最搭，所以选择一。选择以后，Claude Code 就会继续帮我们添加音频并且更新代码。代码改完以后我们再用真机测试一下，这里让 Claude Code 重新构建 App 并且安装到安卓真机上。发送以后等它完成构建和安装，我们直接打开 App 看效果：回到首页点进呼吸模式，听一下这个呼吸般的音效到底怎么样。

### 改用 MiniMax 生成背景音乐

这个效果有点难听，简直让人翻白眼，听起来更像是噪音，和我们想要的呼吸氛围差距很远。所以我们还是不让 Claude Code 自己生成音频，换一种方式来做，这次我们介绍用 MiniMax。MiniMax 是国内的 AI 大模型之一，模型覆盖文本、视频、语音、音乐、图像等多个方向，这次我们就让它来生成一段适合呼吸模式的背景音乐。打开 MiniMax 的音频网站 www.minimax.com，输入斜杠 audio 进入，进入网站以后点击左侧导航栏的音乐创作。因为我们要的是没有歌词的纯音乐，所以先打开歌词里的纯音乐开关；接着在风格这里描述我们想要的音乐效果；写好以后点击下方的创作。稍等一会，它会生成两首音乐，我们分别听一下，选一个更合适的。

### 把音乐接入 Breathe 模式

这一首效果就不错，整体比较平静、轻柔，同时又带一点力量感，放在呼吸模式里很合适，所以我们就选这首，把它的无损音频下载下来。接下来把刚刚下载好的音频拖进相关文件夹，然后在 Claude Code 里用 Add 引用这个音频文件，让它把这段音乐设置成 Breathe 模式的背景音乐。发送以后，Claude Code 会找到 Breathe 模式相关的代码，把我们指定的音频接入进去。代码修改完成以后，我们再打开 App，点击 Breathe 进入呼吸模式，现在一进到页面背景音乐就会开始播放，我们可以根据画面提示吸气、屏住，再慢慢呼气。搭配上新的 BGM，整个呼吸过程的氛围就舒服多了。

### 提交备份收尾

到这里我们的呼吸引导动画和背景音乐就完成了。那接下来还是熟悉的环节，我们把项目目前的代码提交到 GitHub，直接告诉 Claude Code 让它帮我们完成提交和推送。发送以后，Claude Code 就会检查这次的代码改动，等它提示操作完成，这次代码备份就搞定了。我们下期见。
