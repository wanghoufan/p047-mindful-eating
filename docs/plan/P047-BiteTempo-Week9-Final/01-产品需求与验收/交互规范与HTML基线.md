# UI / UX Contract：必须对照真正可操作的 HTML

> 本文连同 `prototype/index.html` 是体验基线；**C 方向已由用户确认并冻结（慢食刻 / BiteTempo）**。Builder 须依现有 ORCA 规则记录 Design Freeze 后开发安卓 UI。不得依据口述概括自行重新发明页面。

## 1. 导航信息架构

- 正常页面底部仅两个 Tab：左「用餐」图标为餐具/时钟，右「心得」图标为笔记，状态包括选中/未选中/点击/焦点，底栏固定、内容独立滚动，留出系统导航/手势安全区。
- 右上角设置入口：显示模式、语言、纯文字提醒间隔（可关闭）与动画、AI Provider/API Key；**没有音频播放或振动设置**；不是底部第三 Tab。
- 沉浸计时页面保持底部两个 Tab 可用；切换时计时状态不消失；如果未来需要隐藏，须通过用户明确 UI 变更授权。
- 返回：设置→来源 Tab；语音中先停止/取消并保留已得到的文字；正在计时按系统返回时不默默结束。

## 2. 全状态 UI 映射

| 页面/状态 | 必须出现 | 点击效果 / 失败场景 |
|---|---|---|
| 用餐初始 | 光球、10:00、四组预设、开始、1 句短标语 | 时长切换立即更新；计时前不倒数；计时下方已有一句静态文字提醒 |
| 用餐进行中 | 呼吸球轻动、剩余时间、暂停、结束 | 暂停时间冻结；切换 Tab 不丢计时；倒计时下方自动无声轮播一句提醒 |
| 用餐暂停 | 光球暂停或弱化、继续、结束 | 继续从剩余秒数恢复；文字轮播的间隔计时同时暂停/恢复 |
| 结束确认 | 明确区分取消与确认结束 | 取消恢复之前状态；确认写入实际时长 |
| 达标 | 显示 00:00 和“目标时间已到” | 用户决定何时结束，不强制继续进食 |
| 心得初始 | 大“AI 语音记录”按钮、可编辑文本区、心得历史 | 无语音服务时展示可操作的手动路径 |
| 系统语音中 | 明确“正在听”、停止/取消状态 | 权限弹窗、无服务、超时须测试 |
| 原文待整理 | 原文字段可改、“AI 整理”和“直接保存” | 草稿先持久化 |
| AI 等待/成功/失败 | 加载取消或重试、润色结果、原文对照 | 保留原文；失败可继续编辑/保存 |
| 历史心得 | 日期、正文、编辑、删除 | 删除一条前确认，保存后刷新列表 |
| 设置 | LIGHT/DARK/SYSTEM、zh/en/FOLLOW_SYSTEM、文字轮播间隔（含关闭）/减少动画、模型设置；不设声音或振动开关 | 退出再进入仍生效，改设置不丢草稿 |

## 3. 已批准的唯一视觉方向 C

**2026-10-11 用户正式选择 C「慢食刻 / BiteTempo」**：深灰 / 墨绿 / 薄荷绿、略方组件、几何光球与醒目时间数字。`prototype/index.html` 已锁定 C；旧 A/B 方案不再进入正式交接包。**这属于视觉与品牌确认，不代表正式开发阶段 Human Gate 授权。**

轻量计时页面的文字位置：倒计时下方固定容器，只呈现当前一条提示；60 秒默认间隔自动淡入换句，可改 30 / 90 / 120 秒或关闭。没有下一句按钮，不使用提示音、语音播报、音乐、振动；暂停同时停轮播，恢复则继续等待至下一次换句；目标时间到了只显示文字。

## 4. HTML 原型功能逐条说明

- 可用：两个 Tab、默认 10 分钟与预设切换、真实倒数、暂停/恢复/结束确认、标语自动无声轮播（可调间隔/关闭）、历史心得保存/删除/编辑、设置中的语言、光效和配色变体。
- HTML 的“AI 语音记录”：**只聚焦输入框并提示使用系统键盘麦克风**，因为 Web 页面不能可靠调用所有安卓原生语音识别能力。**正式 App 必须实现 Android SpeechRecognizer / RecognizerIntent 等原生交互**，且 Android 的语音提供方可能联网，不得许诺全程离线。
- HTML 的“AI 整理预览”：仅当点击“填入演示口述”时展示一份固定的示例润色结果，**没有调用 DeepSeek**。用户自己输入的任意话不会被原型假装由模型改写；正式 App 才发真实模型请求。
- `prototype/screenshots/` 里的图片来自**浏览器渲染的 HTML 原型**，不是安卓 APK 的真实运行图，严禁拿来冒交作业要求的 App 截图。
- 官方品牌资产已冻结为 `prototype/branding/C/` 的图标、透明 adaptive 前景和启动页。Builder 仍须按实际 Expo / Android 约束完成图标掩膜、启动屏布局与真机检验。

## 5. QA：必须对比同一设备尺寸截图

开发者截屏三组：HTML 原型（手机预览宽度 390px 左右）/ APP 安卓实机 / 差异清单。逐一比对：球体立体感、主按钮位置、剩余时间、两 Tab、设置入口、原文/润色双区、删除按钮与安全区、小屏滚动、软键盘避让、深浅色和英文长词。UI 修改只做最小增量，不得一次性重做已经批准的风格。

## 6. 不能写入用户可见页面的内容

FR/AC、Human Gate、模型 ID、Token 统计、架构名、Source ID、测试状态“PASS”、开发版本 hash 等只放开发材料。用户只看清楚操作、结果与下一步；重要的 AI 文本发送与语音服务提示在必要时呈现。
