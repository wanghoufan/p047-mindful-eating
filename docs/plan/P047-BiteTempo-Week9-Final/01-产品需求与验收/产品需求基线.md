# P047 正念吃饭 · 产品需求基线（正式 Spec Kit 的输入材料）

文档类型：**Spec Input**（非 `specs/001-.../spec.md`，不能代替 `/speckit.specify`）  
版本：V1.3 / 2026-10-11（用户已确认 C 方向品牌和静音自动文字轮播）  
用户：自己高频使用的成年安卓用户  
目标：帮助进食较快的人，通过温和可视化计时和饭后语音心得记录，建立适合自己的慢食习惯。

## 1. 一句话价值主张

**吃饭时轻轻提醒自己慢一点，吃完后把心得说出来，自动整理成清楚的个人记录。**

## 2. 范围冻结

### P0：核心必做

- FR-01 双主 Tab：`用餐`、`心得`；设置入口置于顶部，不做第三 Tab；使用真实安卓安全区、系统返回键和软键盘。
- FR-02 用餐前展示光球及目标时长选择：10、12、15、20 分钟；首开默认为 10 分钟，后续记忆选择。
- FR-03 计时状态必须覆盖 `未开始 → 进行中 ↔ 已暂停 → 完成/提前结束`；剩余时间不因切后台或锁屏出现倒退/重复；回到前台按实时时间纠正。
- FR-04 完整用餐过程轻柔循环光球动画，避免剧烈闪烁；无须屏息、无须把吸吐气节拍绑到吞咽。允许减少动画。
- FR-05 **倒计时正下方始终仅显示一条文字提醒**；进行中按可设置间隔**自动**轮播（建议默认 60 秒，备选 30/90/120 秒或关闭），短暂淡入淡出；**无下一句按钮、无 TTS 语音、无提示音、无背景音乐、无振动、无强制通知**。暂停同步暂停提醒切换，继续后恢复剩余间隔；到时保持文字提示但不发声。
- FR-06 允许随时暂停、继续、提前结束；提前结束应确认，吃饱时允许结束，不强迫继续吃；达到 0 后展示“目标时间已到”，不会强制结束或自动奖励式健康判断。
- FR-07 本地保存每次会话目标、实际用餐秒数、日期、完成状态；不储存音频。
- FR-08 心得支持点击“AI 语音记录”发起**系统语音识别**，优先 Android SpeechRecognizer / RecognizerIntent 能力（是否内置离线由设备决定）；文本识别成功后进入可编辑原文区。
- FR-09 系统识别无权限、无服务、语言不支持、超时、取消或失败时必须清楚提示；允许使用**系统键盘语音输入**或手动输入，任何已有文字均不丢失。不得自行添加第三方 ASR 云服务。
- FR-10 通过统一 `TextPolishProvider` 接口调用 AI，仅整理用户原文。首个 Provider：DeepSeek。任务是删除口水词、重复、修复标点/轻微语病，**保留第一人称、事实、情绪、关键时间和方法**。严禁添加未经用户说出的分析、建议、诊断、评价。
- FR-11 整理前自动保存原文字稿为本地草稿；整理结果与原文对照，允许修改、重新整理、保留原文、取消，用户明确确认后写为最终心得。
- FR-12 新增、查看、编辑、删除历史心得；本地持久化，无网络也可浏览记录。删除须确认并针对单条，无误删整库。
- FR-13 DeepSeek 设置为用户自己填写 API Key（BYOK），安全储存并可清除。无 Key 时提示输入并允许原文保存；Key 不许硬编码、日志打印、放在 HTML、放 EXPO_PUBLIC 或推送 Git。
- FR-14 冻结品牌 **慢食刻 / BiteTempo（C 极简科技风格）**，不采用 A/B 候选；三态主题 LIGHT/DARK/SYSTEM（默认 SYSTEM）及 zh-CN/en/FOLLOW_SYSTEM（默认 FOLLOW_SYSTEM），设置存储；切换不丢计时与录入文本，语言回退 zh-CN；首版至少中文和英文基础 UI 文案。
- FR-15 离线可用范围：计时/光球/提醒/心得编辑与浏览；AI 润色需要网络及有效凭证（除非以后明确改方案）。系统语音识别本身的离线能力**不能保证**。
- FR-16 安卓 Development Build 真机安装与关键路径实测；最终生成可以供个人独立打开的测试/安装 APK（区别开发测试包和真正可离线运行的包）。

### P1：低成本完善

- FR-17 用餐完成后的明显但不强制的“记录一点心得”入口。
- FR-18 设置仅包含提示文字频率/关闭、动画减弱与其他必要偏好；**不新增声音、铃声、播放或振动开关**。
- FR-19 未保存草稿被系统中断时可找回；重复点击整理/保存不生成重复记录。

### 不做（明确排除）

- 不做 AI 饮食建议、健康诊断、自动分析原因、趋势推断、自动评分。
- 不做后台全程录音、录音上传、第三方 ASR/STT API、自动聊天、聊天历史、自动知识总结。
- 不做强制憋气、进食中跟随固定呼吸时长、强迫吃够 10 分钟、饥饿/饱腹诊断。
- 不做会员、付费、社交、云同步、公共分享、云数据库、营养热量/血糖推断。
- 不引入无需求的复杂白噪音混音台、冥想课程、登录系统、用餐提醒声效或 TTS 播报；心得的系统语音识别是输入能力，不是用餐语音提醒。

## 3. 用户路径（必须端到端可运行）

### FLOW-01 轻量慢食

打开 APP → “用餐” Tab → 选 10/12/15/20 分钟 → “开始用餐” → 光球缓慢变化、时间倒数、下方文字按间隔自动轮播（静音） → 暂停/继续（可选）→ 提前结束或到达目标 → 保存会话实际秒数 → 返回用餐或前往心得。

### FLOW-02 语音心得

切换“心得” → 点击“AI 语音记录” → 系统语音识别开始，授予麦克风权限（仅首次）→ 口述 → 停止或系统结束 → 展示可编辑原文 → “AI 整理” → 文本变通顺但不变意 → 展示修改前后 → 用户可编辑 → 点击保存 → 历史心得出现记录。

### FLOW-03 失败退化

无系统识别服务/权限拒绝/识别空结果 → 原文文本框可用 → 用户手动或用键盘语音输入 → 可直接保存，不要求 AI 成功。若 DeepSeek 认证/额度/网络失败 → 原文保留、错误可读、稍后重试，不丢草稿。

### FLOW-04 返回与切换

进行中切换到心得 / 锁屏 / 回前台 → 会话状态和累计时间一致；心得编辑中切去用餐再返回 → 草稿保留；设置切换主题与语言 → 当前输入与计时不丢失。

## 4. 核心数据（字段建议，计划阶段可按现有规范定型）

- MealSession: `id`, `startedAt`, `endedAt`, `targetSeconds`, `actualSeconds`, `finishReason` (`reached_target`/`early_end`), `createdAt`。
- MealNote: `id`, `sessionId?`, `rawText`, `finalText`, `createdAt`, `updatedAt`, `polishedBy?`, `revision`。
- LocalSettings: `durationPreset`, `themeMode`, `languageMode`, `reminderEnabled`, `reminderIntervalSeconds`, `reduceMotion`。
- ProviderConfig: `providerId`, `modelId`, `transportMode`; API Key 仅在 SecureStore，不在普通数据库或导出。
- SessionState: `status`, `remainingAtPause`, `startTimeMonotonic/elapsed`, `backgroundAccounting`；持久化策略见 PLAN，避免 `Date.now` 系统改时引起的误差。

## 5. 关键验收（AC 候选，真正编号由 Spec Kit 与 ORCA 交叉映射）

| ID | 用户操作 | 明确可见的合格结果 |
|---|---|---|
| AC-01 | 首次打开用餐 | 默认 10:00、球体及开始按钮完整显示 |
| AC-02 | 切换 12/15/20 分钟 | 倒计时初始值准确更新，未开始状态不误倒数 |
| AC-03 | 开始并暂停 | 时间减小；暂停期间静止；继续后不跳回初始值 |
| AC-04 | 离开前台后返回 | 根据实际经过时间还原，不发生倒数重复/变快 |
| AC-05 | 手动提前结束 | 出现确认；取消不结束；确认存正确实际秒数 |
| AC-06 | 达目标 0:00 | 提示到达目标，用户仍可按需结束；不出现负计时 |
| AC-07 | 持续观看光球 | 动效稳定、不闪烁；减少动画后无强制运动 |
| AC-08 | 开始计时，跨越提醒间隔→暂停→继续 | 倒计时下方每次只显示一句；到间隔自动换下一句，无下一句按钮/音效/TTS/振动；暂停时间内文案不切换，恢复后继续；设置关闭后隐藏 |
| AC-09 | 点击 AI 语音记录 | 系统能力可用时启动识别；不支持时明确回退，绝不默默无响应 |
| AC-10 | 完成一次口述 | 文字准确落入原文区、能编辑，原始内容不丢 |
| AC-11 | 触发 DeepSeek 整理 | 仅润色去口水词，无“饮食建议”“原因判断”或虚构事实 |
| AC-12 | 无网络/Key/余额/权限 | 错误反馈清楚，草稿可继续编辑与保存 |
| AC-13 | 查看/改/删心得 | 持久化正确；删除须确认，仅作用一条 |
| AC-14 | 切换主题/中英 | 随系统/手动切换有效，业务状态与文本不丢 |
| AC-15 | 安装安卓开发包 | 安卓真机真开、真点、真输入、真计时并留证据 |
| AC-16 | 审查声称作业完成 | Spec Kit 真实命令与产物、≥3 张真实 App 截图齐备 |
| AC-17 | 查看原型对照 | 导航/页面层级/字体/光球/自动轮播文案/按钮状态符合冻结的 C 方向 HTML 基线（慢食刻 / BiteTempo） |
| AC-18 | 检查秘密信息 | APK 无硬编码 Key，日志/仓库无凭证，公开发布时走授权云函数 |

## 6. 医学、安全与信息边界

产品是行为习惯工具，不暗示通过延长时间必定改善血糖或胃病；避免“防治、诊断、保证减肥”等承诺。食物吞咽期间保持自然呼吸，不指导刻意屏息。页面文案简洁、不出现 FR、Gate、内部风险评分、模型 Token 消耗等技术信息。对用户必须知道的麦克风、AI 数据上传与删除行为，应在相应场景清楚提示。
