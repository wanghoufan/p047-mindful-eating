# HTML 交互原型：使用说明

## 如何打开

- 电脑直接双击 `index.html`；无需编译、无需后端、无需 npm install。
- 也可在 VS Code 打开该文件进行预览。手机可以通过电脑局域网受控静态服务器查看，但此 HTML 原型**不是 APK 或可安装 PWA**。

## 你能点击什么

1. 左侧主操作「用餐」：选 10 / 12 / 15 / 20 分钟 → 开始计时 → 暂停 → 继续 → 结束并确认；倒计时下方短句默认每 60 秒自动无声轮播，暂停则停止轮播。
2. 底部切换「心得」：点击语音记录按钮进入输入区；点击「填入演示口述」和「AI 整理预览」会展示**预设样例**去口水词效果；你可以修改整理结果再保存，也能手动输入并直接保存，之后编辑/删除历史。
3. 右上角齿轮打开设置，切换 LIGHT/DARK/SYSTEM、zh-CN/en/FOLLOW_SYSTEM、减少动画等。设置与心得演示尝试保存到浏览器 localStorage（本地浏览器阻止时可能无法持久化）。
4. 桌面与手机都锁定 **C 方向（慢食刻 / BiteTempo）**；设计已获得用户确认，A/B 不再提供。

## 和真实 APP 不同的地方

- Web 原型不能可靠直接使用 Android 原生 `SpeechRecognizer`：按钮显示解释并将焦点放到文本框；在 Android 浏览器可尝试用**系统输入法麦克风**，但不同输入法能力不同。
- 这个 HTML **不连接真实 DeepSeek / 任何 AI API，也不收集 API Key**。点击「AI 整理预览」只有固定演示口述内容可以展示固定整理结果；如果是自己输入的文字，不会凭空伪装 AI 已经修改。
- 计时/历史数据模拟真实操作，但实际 Android 版要采用可靠后台时钟/SQLite 与 Android 系统权限，不能从此 HTML 直接打成 WebView APK 交作业。
- `screenshots/` 是真实浏览器渲染的原型图片，**不是安卓 APP 截图**。
- `branding/C/` 提供用户批准的图标、adaptive 前景和启动页参考素材；正式 Android 资源适配仍须真机验收。

## 开发验收的对照方式

请根据当前用户批准的 HTML 方向，在同尺寸屏幕下逐状态比对：文字层级、光球立体效果/动画、目标时长、开始/暂停/结束按钮、底部双 Tab、心得输入与 AI 前后对照、键盘遮挡、深浅色、中英内容。差异记录到项目 `docs/qa` 并修复。不允许只附一张静态原型就声称 100% 还原。

## 品牌最终冻结 C

- 只使用「慢食刻 / BiteTempo」与 `branding/C/` 下品牌资产。`branding/index.html` 仅显示 C。
- HTML 没有音频、TTS、振动或下一句按钮。用餐文字默认 60 秒自动换句，可在设置调整为 30/90/120 秒或关闭。暂停/继续同步控制提醒节奏。
- 心得语音输入是另一个场景：正式安卓调用系统语音识别，不改变静音提醒原则。
