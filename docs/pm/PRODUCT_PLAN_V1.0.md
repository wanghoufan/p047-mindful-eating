# P047 慢食刻 / BiteTempo · PRODUCT_PLAN

> 本计划由唯一开发者（单智能体模式）依据用户已确认的《P047-BiteTempo-Week9-Final》交接包（V1.3）整理而成。产品需求、C 方向品牌、UI/交互与技术选型**均已由用户确认（2026-10-11）**，不再重复征询；本文件是把已确认内容登记为 ORCA Phase1 正式计划，供 Human Gate 放行。

- Plan Version：V1.0
- PROJECT_PHASE：WAITING_HUMAN_APPROVAL
- Product Goal：帮助进食较快的人，通过**温和可视化计时**和**饭后语音心得**，逐步建立适合自己的慢食习惯。
- Target Users：自己高频使用的成年安卓用户（单用户、个人本地使用；首版 BYOK，不做账号与云同步）。
- Problem：吃饭常吃太快、注意力被手机带走；想记录心得但打字麻烦，事后想回看却没有清楚的个人记录。
- Core Value：吃饭时轻轻提醒慢一点（发光光球 + 倒计时 + 一句无声文字提醒），吃完把心得说出来，AI 只做去口水词的整理，形成可回看的第一人称记录。
- User Flow：
  - FLOW-01 轻量慢食：打开 → 「用餐」Tab → 选 10/12/15/20 分钟 → 开始 → 光球缓动 + 倒数 + 倒计时下方一句无声文字按间隔自动轮播 → 暂停/继续 → 提前结束或到时 → 保存本次实际秒数 → 回用餐或去心得。
  - FLOW-02 语音心得：「心得」Tab → 点「AI 语音记录」→ 系统语音识别（仅首次授权麦克风）→ 口述 → 停止 → 可编辑原文 → 「AI 整理」→ 前后对照 → 编辑/保留/取消 → 确认为最终心得 → 历史出现。
  - FLOW-03 失败退化：无系统识别/权限拒绝/空结果 → 原文框可用，可用系统键盘语音或手动输入 → 不做 AI 也能直接保存；DeepSeek 认证/额度/网络失败 → 原文保留、错误可读、可重试、不丢草稿。
  - FLOW-04 返回与切换：计时中切 Tab / 锁屏 / 回前台 → 状态与累计时间一致；编辑心得时切走再回 → 草稿保留；切主题/语言 → 计时与输入不丢。
- Functional Scope（P0 必做）：双主 Tab（用餐/心得）+ 顶部设置入口；10/12/15/20 分钟光球计时与可重入状态机；倒计时下方**单句无声自动文字轮播**（默认 60s，可设 30/90/120s 或关闭，暂停同暂停）；系统语音识别 + 键盘语音/手动兜底；统一 `TextPolishProvider` + DeepSeek 只做去口水词整理；原文/整理对照、编辑、本地持久化；历史心得增删改；BYOK 密钥 SecureStore；主题三态与中英双语；离线核心可用；安卓 Development Build 真机验证 + 可独立安装 APK。
- Out of Scope（明确排除）：AI 饮食建议/健康诊断/趋势评分；第三方 ASR/云 STT；后台录音与上传；白噪音混音台/冥想课程/TTS 播报/提示音/振动（**用餐提醒全程静音**，只显示文字）；会员/付费/社交/云同步/云数据库；强制憋气或为凑时长继续吃；登录系统。

## 核心任务与 MVP 边界（照 `docs/sop/app-simplicity.md` Gate A）

- 核心任务（一句话）：**吃饭时开始一次计时，让自己慢下来，吃完口述一段心得并保存。**
- 高频功能：开始/暂停/继续/结束计时；口述→整理→保存心得。
- MVP 必含（每项对应核心任务或高频功能）：光球计时与预设时长、无声文字轮播、语音/手动录入、AI 去口水词整理、原文对照、本地保存与历史、设置（时长记忆/提醒间隔/主题/语言/Provider Key）。
- 可延后/可隐藏/可取消清单（轻量项目口径）：设置中的「减少动画」保留（无障碍必要）；「整理后重新整理」保留（失败可恢复）；**可延后**：用量统计、导出、深色自动定时等增强项——本版不做，不列入 MVP。**经核，MVP 无用同一状态下用途重复的入口，无须额外删减。**
- 交付形式判断：**React Native + Expo（安卓首发）**。理由：需要**原生系统语音识别（Android SpeechRecognizer）**、SecureStore、后台计时与真机安装，纯 Web/PWA 无法满足系统语音与原生能力要求；HTML 原型只作视觉与交互冻结基准，**不以 WebView 包装 HTML 冒充原生实现**。
- 治理强度分级（逐条依据）：安全风险＝中（涉及麦克风、向第三方发送文本、BYOK 密钥）；设备能力＝高（系统语音、后台计时、原生构建/APK）；数据敏感度＝中（口述原话本地存储，密钥 SecureStore）；异常恢复＝高（断网/AI 失败/系统语音不可用/后台计时）；用户操作复杂度＝低（两 Tab、单主任务）。判定级别＝**标准**（非轻量）。未削减五类验收：安全告知与停止条件、隐私与授权、数据正确性、异常与中断恢复、真机基本可用性——全部保留。
