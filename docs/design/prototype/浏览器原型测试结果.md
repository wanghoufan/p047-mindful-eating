# P047 慢食刻 / BiteTempo：V1.3 HTML 原型复测

## 增量原型 v2（stats-v2.html）冒烟测试 — 2026-10-12

**范围**：统计 Tab（A1/B1/C1/D1 拍板项）+ 首页布局修正的原型验证。模拟数据，非真实 APP 验收。

- 方式：浏览器自动化（本地静态服务 http://127.0.0.1:8747/stats-v2.html），两轮共 13 项检查。
- 第一轮 8 项 PASS，发现 3 个缺陷：①启动即抛 `L.side.p1` undefined（`L` 误指向 ctl 对象）导致首屏手机内容空白；②页标题渲染成 `[object Object]`（`pageTop` 收到 i18n 对象而非字符串）；③语言切换不刷新手机内容。
- 修复后第二轮 5 项全 PASS：console 全程无错误；统计页标题/卡片/柱状图/记录列表正常；用餐页光球垂直居中、按钮贴底；计时→结束确认→提前结束流程正常；心得页关联用餐徽标（12:00）显示；中英切换即时生效；深浅色切换正常。
- 结论：原型可交付用户确认。已知限制：模拟数据、语音为提示演示。

# 以下为 V1.3 旧版原型复测记录（2026-10-11）

**范围**：C 已确认视觉方案；HTML 静态原型与浏览器交互。**不是 Android App / DeepSeek / SpeechRecognizer 验收。**

执行：2026-10-11；Chromium 无头浏览器，Playwright 手机视口 390×844，zh-CN。由于当前浏览器导航策略限制，通过 `page.set_content` 装载原型 HTML 并在测试夹具内嵌入本地 C 图标素材，未测试 `file://` 导航本身；源码中的相对资源路径另做静态文件存在性核验。

已实际通过的浏览器行为：

1. 只加载 C「慢食刻」，没有 A/B 切换、没有 `下一句` 按钮。
2. 文字提示处于倒计时下方，一次一条，默认每 60 秒自动换下一句；页面无 `<audio>` / `<video>` 标签，代码未实现 TTS/振动/音频提示。
3. 开始后使用浏览器虚拟时钟快进 61 秒，10:00 → 08:59，显示的提示语自动改变。
4. 点击暂停，再快进 120 秒，倒计时和提示语都保持不变。
5. 设为 30 秒后继续并快进 31 秒，提示语再次改变；设置关闭后提醒隐藏。
6. 语言选英文、主题改浅色后，标题显示 BiteTempo；恢复中文深色继续操作。
7. 切到心得，加载固定演示口述，显示固定示例润色；保存后历史记录出现。**未请求真实 DeepSeek。**
8. 结束确认的取消不结束；确认后仅增加一条会话。屏幕宽度没有出现水平溢出。
9. 浏览器页面错误监听为零；JavaScript 通过 `node --check` 语法检查。
